# 文字可见性修复说明

## 问题描述

页面上的"粒子控制"标题文字不可见。

## 原因分析

使用了CSS渐变文字效果：
```css
background: linear-gradient(135deg, #ffffff, #e0b3ff);
-webkit-background-clip: text;
-webkit-text-fill-color: transparent;  /* 这行导致文字透明 */
```

这种技术虽然可以创建渐变文字效果，但在某些情况下会导致文字完全不可见，特别是当`text-shadow`与`-webkit-text-fill-color: transparent`同时使用时。

## 解决方案

改用更简单可靠的方法：
```css
color: #ffffff;  /* 使用纯白色文字 */
text-shadow: 0 0 20px rgba(138, 43, 226, 0.8), 0 2px 4px rgba(0, 0, 0, 0.5);  /* 添加发光效果 */
```

## 修复效果

- ✅ "粒子控制"标题现在清晰可见
- ✅ 保留了紫色发光效果
- ✅ 文字有良好的对比度和可读性
- ✅ 所有其他文字元素正常显示
