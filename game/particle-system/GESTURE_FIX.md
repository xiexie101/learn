# 手势检测修复说明

## 修复内容

### 1. ✅ 移除抓取手势
- 删除了 `detectGrab()` 函数的调用
- 移除了抓取手势的UI指南
- 简化了手势检测逻辑

### 2. ✅ 改进旋转检测
**问题**：旋转不起效果

**修复**：
- 降低旋转检测阈值：从 `0.05` 降到 `0.02`
- 增加旋转放大倍数：从 `2x` 增到 `3x`
- 添加角度跳变处理（-π到π边界）
- 更容易触发旋转效果

```javascript
// 旋转检测改进
if (Math.abs(rotationDelta) > 0.02 && Math.abs(rotationDelta) < 0.5) {
    targetRotationAngle += rotationDelta * 3; // 增加放大倍数
}
```

### 3. ✅ 优化握拳检测
**问题**：握拳可能不容易被识别

**修复**：
- 放宽手指弯曲判断：从 `1.1` 到 `1.2`
- 放宽拇指距离：从 `0.15` 到 `0.18`
- 更容易检测到握拳手势

### 4. ✅ 优化张开手检测
**问题**：张开手可能不容易被识别

**修复**：
- 降低手指伸展阈值：从 `0.15` 到 `0.12`
- 降低手指张开度阈值：从 `0.4` 到 `0.3`
- 更容易检测到张开手势

| 手势 | 效果 | 说明 |
|------|------|------|
| ✊ 握拳 | 粒子收缩到30% | 所有手指弯曲 |
| 🖐️ 张开 | 粒子扩散到250% | 五指伸展并张开 |
| 🔄 旋转 | 场景旋转 | 左右旋转手腕 |

## 测试建议

1. **握拳测试**：
   - 将手伸向摄像头
   - 紧握拳头
   - 应该看到粒子快速收缩

2. **张开测试**：
   - 将手伸向摄像头
   - 五指完全张开并分开
   - 应该看到粒子向外扩散

3. **旋转测试**：
   - 将手伸向摄像头
   - 保持手掌平展
   - 左右旋转手腕
   - 应该看到粒子系统跟随旋转
