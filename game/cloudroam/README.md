# CloudRoam Active (云游·不老松)

## 简介
这是一个专为老年人设计的“数字疗法”游戏，通过身体摆动（Body Sway）来控制游戏角色，锻炼平衡能力和核心稳定性。

## 🎮 如何开始 (How to Play)

1. **环境准备**
   - 将设备（手机/平板/电脑）放置在平稳的桌面上。
   - 站在距离屏幕约 **1.5 米 - 2.0 米** 的位置。
   - 确保光线充足，且身后有足够的安全空间（建议身后放置稳固的椅子以防万一）。

2. **启动游戏**
   - 打开浏览器访问游戏页面。
   - 浏览器会请求**摄像头权限**，请点击“允许”。

3. **操作指南**
   - **校准**: 保持自然直立站姿，点击屏幕上的 **"开始旅程"** 按钮。系统会以此刻的姿态作为“中心点”。
   - **移动**: 
     - 身体向**左**倾斜 -> 角色左移
     - 身体向**右**倾斜 -> 角色右移
     - 身体**回正** -> 角色在惯性下慢慢回正
   *注意：是依靠上半身的倾斜，而不是走步。*

4. **游戏目标**
   - ✅ **收集**: 撞击路上的 **绿色菱形**（特产），每个 +10 分。
   - ❌ **躲避**: 避开路上的 **红色尖刺**（水坑/障碍），撞到 -5 分。
   - ⚠️ **结束**: 如果分数跌至 0 以下，旅程结束。

## 🛠 本地运行
如果在本地开发环境运行：
```bash
# 在项目根目录启动 HTTP 服务器
python3 -m http.server 8080
# 浏览器访问
http://localhost:8080/cloudroam/
```
