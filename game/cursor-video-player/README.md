# 光标交互插帧播放器 (Cursor Video Player)

基于用户光标位置与物理惯性渲染的交互式视频播放器，专为 `keyint=1`（All-Intra 全关键帧）视频设计，配备**亚帧级（Sub-Frame）连续插帧算法**与多种交互操控模式。

---

## 🌟 核心特性

1. **亚帧连续插帧 (Sub-Frame Alpha Blend Interpolation)**:
   - 普通视频在 24 FPS 下逐帧移动有明显的离散顿挫感。
   - 本播放器采用双帧时域插值算法，在光标滑动到任意小数值帧（如 `Frame 54.38`）时，自动将第 54 帧与第 55 帧进行像素级 Alpha 渐变融合，获得极其丝滑的高帧率电影质感。

2. **物理阻尼惯性引擎 (Exponential Lerp & Physics Damping)**:
   - 杜绝传统光标拖动的生硬手感。
   - 内置阻尼惯性模拟（`currentProgress += (target - current) * lerpFactor`），支持在参数面板中自由调节从“丝滑流动惯性”到“1:1 瞬时响应”。

3. **趣味交互模式**:
   - **⇄ 水平光标滑动**：标准的视频时间线交互。
   - **↻ 圆周转圈操控 (猫咪同步)**：专为《猫咪转圈圈》视频打造！鼠标绕视频中心画圈，猫咪就会实时同步追随你的光标旋转步伐。
   - **⛶ 全屏视口跟随**：将鼠标滑动范围扩展至整个浏览器视口。
   - **滚轮 / 触控板平滑擦洗**：双指滑动随时微调。

4. **双引擎比对**:
   - **Canvas 亚帧插值引擎**：微观混合，极致平滑。
   - **原生硬件 All-Intra 视频引擎**：直接硬解 MP4，体验 `keyint=1` 带来的零延迟即时 Seek 体验。

---

## 🚀 启动与预览

你可以直接在本地静态服务或使用 Python 启动本地服务器：

```bash
# 进入目录
cd webapp/cursor-video-player

# 启动本地服务
python3 -m http.server 8088
```

浏览器访问：`http://localhost:8088`
