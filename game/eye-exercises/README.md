## 🌟 核心看点与科学认知

1. **睫状肌伸懒腰（橡皮筋比喻）**：
   - 长时间盯书盯屏幕，眼内睫状肌像死死绷紧的橡皮筋；
   - 闭眼与轻按摩的核心意义在于打断持续用眼，让痉挛的肌肉弹簧松弛回弹、恢复血流。

2. **眼轴拉长与物理边界（橄榄球比喻）**：
   - 真性近视的本质是眼轴变长（眼球从圆足球拉长为小橄榄），眼轴每多长 1 毫米加深 200~300 度；
   - 手指揉穴位无法缩短眼轴，绝不能轻信“做操治近视”的虚假神话；它的定位是缓解疲劳的辅助工具。

3. **版本演变背后的公共卫生考量**：
   - 从 8 节、4 节到现行 5 节/6 节，最核心的变化是**避免脏手抠内眼角（挤按睛明穴）造成细菌感染**；
   - 确立“做操前流水洗手”第一铁律，改“轮刮眼眶”为“刮上眼眶”，新增枕后风池穴（颈椎放松）与耳垂抓地（全身联动）。

4. **现行六节操极简穴位图谱**：
   - 1. 按揉攒竹穴（眉头凹陷，轻揉画圈）
   - 2. 按压睛明穴（内眼角鼻骨旁，轻按不压眼球）
   - 3. 按揉四白穴（瞳孔直下颧骨小凹，指托下巴小幅揉）
   - 4. 按揉太阳穴刮上眼眶（拇指按太阳，食指内侧刮眉骨）
   - 5. 按揉风池穴（后脑勺枕骨下凹陷，二指并拢揉大筋）
   - 6. 揉捏耳垂、脚趾抓地（耳垂眼穴与十趾抓地同步）

5. **近视防控金字塔（战斗力阶梯）**：
   - 🥇 **核心主力（基石）**：每天日间户外活动累计 2 小时（阳光刺激视网膜分泌多巴胺，阻断眼轴增长）；
   - 🥈 **中坚防线**：一拳一尺一寸读写姿势、良好采光、30~40 分钟远眺；
   - 🥉 **贴心辅助**：每日 2 次眼保健操。

## 🛠️ 交互功能

- **Web Audio 课间 5 分钟护眼节拍器**：
  - 80 BPM 舒缓节奏，四八拍自动报拍与切换节次；
  - 纯原生 Web Audio API 合成五音和弦，无需外部音频资源，离线即用；
