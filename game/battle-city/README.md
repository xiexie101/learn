# 经典小霸王坦克大战 · NES Battle City 🎮

> 100% 纯原生纯前端高保真复刻 1985 年任天堂红白机（NES / Famicom）经典《坦克大战》（Battle City）。
> 零外部音频/图像依赖，基于 HTML5 Canvas + Web Audio API 动态合成器实现像素级还原与流畅游玩体验。

---

## 🌟 核心特性与技术亮点

### 1. 经典物理与操控手感 (Authentic Gameplay & Physics)
- **半砖走位对齐 (Half-Tile Alignment & Snapping)**：
  - 完美复刻红白机坦克在垂直/水平变向时的 8 像素网格吸附补正算法。
  - 在进入 8 像素或 16 像素狭窄通道时不会被墙角切角卡死，拐弯极度顺滑。
- **经典冰面惯性滑行 (Ice Sliding)**：
  - 坦克行驶在冰面上时松开方向键会产生真实惯性滑行阻尼。
- **精准半砖摧毁机制 (Half-Brick Destruction)**：
  - 炮弹尺寸为 4×4 像素，支持击中砖缝时同时摧毁相邻的 8×8 砖块，还原原版经典的打砖开道手感。
- **破铁机制 (Steel Piercing)**：
  - 白铁墙对普通炮弹绝对免疫（伴随清脆金属反弹音效）。
  - 当玩家吃星星升级至 **3星重型坦克** 时，获得破坏白铁墙的能力！
- **战术双层渲染 (Dual-Layer Foliage Rendering)**：
  - 地面层（砖墙、铁墙、水面、冰面、老鹰基地）与物体层（坦克、炮弹、爆炸、宝物）之上，独立叠加 **森林遮挡层 (Trees Overlay)**。
  - 坦克与炮弹在森林下自由穿行隐匿，完美还原原版利用丛林伏击的战术趣味。
- **水面与老鹰基地防御**：
  - 水面阻挡坦克通行，炮弹自由飞过。
  - 双方任何炮弹击中老鹰基地，基地化为废墟并立即触发 Game Over。

### 2. 原版四大敌军坦克服役
1. **普通坦克 (Basic Tank)**：慢速移动，基础弹速，击毁得 100 分。
2. **轻型装甲车 (Fast Tank)**：高速飞驰，机动性极强，击毁得 200 分。
3. **高炮重装坦克 (Power Tank)**：标准车速，高速穿甲穿透弹，击毁得 300 分。
4. **重型装甲车 (Armor Tank)**：拥有 4 格护甲值，随受创变色（绿 -> 黄 -> 浅蓝 -> 灰），击毁得 400 分。
- **红光闪烁敌坦 (Bonus Tank)**：每关特定批次刷新红光闪烁坦克，击破后立即爆出全屏道具！

### 3. 全套道具系统 (Power-Ups)
- 🪖 **头盔 (Helmet)**：获得 10 秒无敌防护光环。
- ⏱️ **时钟 (Clock)**：冻结全屏所有敌方坦克 10 秒（无法移动与开火）。
- ⛏️ **铁锹 (Shovel)**：将老鹰老巢砖墙一键强化为坚硬铁墙 20 秒，并在最后 4 秒闪烁预警。
- ⭐ **五角星 (Star)**：提升坦克服役星级（1星高速弹 -> 2星双发连射 -> 3星摧毁铁墙）。
- 💣 **手雷 (Grenade / Bomb)**：瞬间炸毁当前屏幕内所有现存敌军坦克，并计入击杀分。
- 🚗 **坦克 (1-UP)**：奖励玩家 1 条额外生命。
- 🔫 **手枪 (Gun)**：瞬间晋升为 3 星重型破铁终极形态。

### 4. 完整关卡流程与战绩统计
- **主界面选关功能 (Stage Select)**：主菜单在「1 PLAYER」状态下按左右方向键（← / → 或 A / D）可自由选择 1 至 5 关快速开启战局。
- **关卡开场过场**：经典灰色帷幕拉开，播放原汁原味红白机坦克大战开场曲，按开火键可快速跳过帷幕动画。
- **通关战绩清算 (Tally Screen)**：
  - 每一关击杀 20 辆坦克后拉起过场帷幕。
  - 逐项清点普通、轻型、高炮、装甲各型坦克的击杀数量与得分，配合经典音效单点递增。
- **内置自定义地图编辑器 (CONSTRUCTION 模式)**：
  - 主菜单选择 CONSTRUCTION 即可进入 26×26 网格地图编辑器。
  - 提供砖墙、铁墙、水面、丛林、冰面、橡皮等画笔，内置关卡1-5预设快速切换。
  - 出生点智能安全防护，严防意外在玩家或敌军刷新区画铁/水导致卡死。
  - 支持一键测试试玩、保存至 LocalStorage、读取自选地图。

### 5. 原生 Web Audio 高保真 8 位合成音效
无需下载任何外部音频 mp3/wav 文件，基于 Web Audio API 振荡器（方波、三角波、噪声缓冲区）纯程序合成：
- 开场经典主旋律（高低双声部方波 + 三角波贝斯走带）
- 引擎巡航与行驶轰鸣（阵亡时自动熄火防漏音）
- 坦克射击、碎砖崩裂、击中白铁清脆反弹
- 炮弹对撞爆炸、坦克大爆炸
- 道具刷新与拾取升调琶音（严格规避水面与铁墙不可达区域）
- 奖命 1-UP 和弦
- 结算界面计数蜂鸣与游戏结束丧钟

### 6. 双端交互支持
- **桌面端**：WASD / 方向键移动，J / 空格射击，K 键连发，← / → 选关，P 暂停，M 静音。
- **移动端**：自适应触控十字方向键（D-Pad）、Select / Start 按键以及 A（开火）/ B（连发）按键，具备手势丢失（touchcancel）防锁死机制与首次交互音频自动解锁。
- **CRT 滤镜**：可选开启/关闭怀旧显像管扫描线与微光晕。

## 🚀 启动方式

本项目为纯原生零依赖设计，无需安装 Node.js 或构建工具：
1. 直接在任意现代浏览器中打开 `webapp/battle-city/index.html`。
2. 或通过任意静态 HTTP 服务器访问（如 `python3 -m http.server 8000`）。
