# 🐦 鹈鹕骑单车 · Pelican on a Bike

> 实时 3D 海岸骑行体验：一只戴着头盔、围着红围巾的白鹈鹕，骑着复古自行车沿海岸线追鱼。<br />
> 黄昏、星空、海浪、海鸟与路灯 —— 全部实时程序化生成，无一张外部贴图。

---

## 🌟 核心特性与工程亮点 (Features & Architecture)

### 1. 🦤 全程序化 3D 建模与双骨骼 IK 骨架 (Procedural Modeling & IK Rigging)
- **鹈鹕生物工程**：流线型羽毛体态、弹性大嘴喉囊（吞鱼与大叫时动态膨胀）、灵动转头机制（视野追踪光标/视线）。
- **双骨骼逆运动学 (2-Bone IK)**：鹈鹕腿部与脚掌通过解析几何 IK 精确锁定在自行车旋转脚踏板上，随踏频实时驱动大腿、小腿与脚踝联动。
- **复古单车精密机械**：经典车架几何结构、辐条车轮旋转惯性、链条与牙盘驱动比、车把转角联动前轮转向与车身横向倾斜倾角（Leaning Dynamics）。

### 2. 🧣 Verlet 物理布料围巾 (Cloth Simulation)
- 基于 Verlet 积分与距离约束的高性能布料粒子链，随单车前进风阻、重力加速度、转弯离心力以及跳跃惯性自然飘扬与抖动。

### 3. 🌊 多频 Gerstner 海浪与次表面散射 (Gerstner Waves & Ocean Shader)
- 结合多组 Gerstner 物理波动函数与有限差分法线，精准呈现海岸浪尖的急促卷浪与深海长周期涌浪。
- 动态次表面散射 (SSS)、浪尖白沫生成、近岸滩涂碎浪泡沫与夜间路灯暖光海面镜面反射倒影。

### 4. 🌅 动态昼夜循环与大气天顶渐变 (Day/Night Cycle & Atmospheric Lighting)
- 太阳、月亮与星空昼夜轨迹推演，从暖橘金黄的黄昏落日、绯紫余霞到深邃星河与冷色月辉。
- 昼夜联动路灯自发光光晕、鹈鹕车灯投射与场景环境雾气融合。

### 5. 🎵 纯原生 Web Audio 生成式合成器 (Procedural Audio Synthesis)
- **机械拟音**：齿轮链条滚动声、飞轮滑行棘轮咔哒声（Freewheel Clicks）、清脆自行车铃音（双频金属共鸣）。
- **生物与环境声**：鹈鹕沙哑鸣叫（共振滤波调制）、海浪拍岸白噪声与海风低频呼啸。
- **生成式交互音乐**：纯代码合成的多声部和弦琶音与轻盈电钢琴旋律，BPM 与节奏紧随踩踏踏频（Cadence）动态变速。

### 6. 🎮 抓鱼趣味游戏循环与成就系统 (Gameplay & Achievements)
- 沿途动态生成普通银鱼与稀有金鱼（5倍积分），支持自动驾驶与变道捕食。
- 飞跃海浪的跃水飞鱼、跳跃抓取加分、连击机制与 14 项隐藏探索成就。

## 🕹️ 控制指南 (Controls)

| 按键 / 操作 | 动作 | 说明 |
| :--- | :--- | :--- |
| **W / ↑** | 加速骑行 | 提高踩踏踏频与前进车速 |
| **S / ↓** | 减速刹车 | 减速滑行，伴随飞轮棘轮咔哒声 |
| **A / D** | 左右变道 | 调整骑行车道以抓鱼或避障 |
| **空格 (Space)** | 跳跃起跳 | 冲跃海浪与飞鱼 |
| **T** | 放手特技 (Trick) | 双翼展开抬前轮绝技 |
| **B** | 按车铃 | 敲响金属车铃，唤起环境共鸣 |
| **H** | 鹈鹕大叫 | 喉囊膨胀发出鹈鹕大叫 |
| **Q / E** | 手动换挡 | 升降速比档位 (1-5 档) |
| **C** | 切换镜头视角 | 自由环绕 / 追随 / 侧面跟拍 / 电影运镜 / 鹈鹕第一视角 |
| **N** | 时间快进 | 快速前进 3 小时体验不同天色 |
| **M** | 音乐开关 | 开启/关闭实时合成背景音乐 |
| **K** | 拍照截图 | 截取当前 3D 渲染画面 |
| **F** | 全屏模式 | 切换全屏沉浸视效 |
| **U** | 极简模式 | 隐藏/显示 HUD 界面 |
| **P** | 游戏暂停 | 暂停渲染与动力学计算 |
| **移动端触控** | 触屏控制 | 自动识别粗触控设备，呼出触控双向按键与动作圆钮 |

## 🛠️ 开发者调试 (Debug & Lil-GUI)

点击右上角 ⚙️ 按钮可呼出内置参数调节面板（Lil-GUI），支持实时调节：
- 巡航模式开关、自动巡航档位
- 太阳高度与时间流速
- 辉光强度 (Bloom)、曝光 (Exposure) 与色差噪点
- 海浪振幅与波形参数
- 鹈鹕头盔/防风眼镜/围巾着装切换
- 音频主音量与音乐分轨音量
