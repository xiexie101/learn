# 🔨 敲打！机器黄鼹鼠 · 马里奥聚会 (Noggin Knock)

> 🎮 100% 纯原生前端高保真复刻 Nintendo Switch《超级马里奥聚会：空前盛会》（*Super Mario Party Jamboree*）经典打地鼠对决。  
> 零外部素材依赖、零重型框架、内置 Web Audio 物理算法合成器与 Canvas 2D 硬件加速渲染，毫秒级秒开，60FPS 极速响应。

---

## 🚀 核心特性

- **双层阶梯立体舞台**：前 5 后 3 共 8 个物理标定地洞，基于 Y-Sorting 深度遮挡管线呈现 2.5D 立体感；
- **双模式无缝切换**：
  - 🕹️ **单排 5 洞极简模式**：针对手机触控与碎片时间研发，Mario 纵向锁定，仅左右横移，屏蔽上排出洞，操作负荷骤降 70%，节奏与爽感翻倍；
  - 🎮 **全域 8 洞标准模式**：支持自由纵深与四向位移，挑战全场掌控力与空间预判；
- **🎯 定制化发泄暴击机制**：自由注入工作与生活痛点标签（如「加班」、「周一」、「Bug」、「甲方」），命中触发专属音效、暴击金币横幅与赛后「发泄战报」；
- **沉浸式双栏合一顶栏**：深色高光毛玻璃设计（`backdrop-filter: blur(16px)`），消除冗余，释放移动端画布至 867px 纵向撑满，彻底消灭黑边；
- **纯原生 Web Audio 声音合成**：挥锤呼啸、橡胶击扁、炸弹引线滋滋、大爆炸、金币叮当等全套音效及 128 BPM 派对 BGM 均由程序底层振荡器实时合成；
- **全端操控兼容**：键盘（WASD / 方向键 + 空格）、触控虚拟双摇杆、屏幕直接轻触直击（Tap-to-Whack）及 Switch 拟物掌机外观切换。

---

## 🕹️ 快速操作指南

### 1. 桌面端键盘 (Desktop)
- **位移**：`W` `A` `S` `D` 或 `↑` `↓` `←` `→`（单排5洞模式下仅需左右移动）；
- **挥锤击打**：`空格键 (Space)` 或 `Enter`；
- **模式切换**：点击顶栏模式切换胶囊按钮；
- **掌机/全屏切换**：点击顶栏掌机图标（🎮 / 🖥️）。

### 2. 移动端触控 (Mobile H5)
- **方式一（点哪打哪·推荐）**：直接用手指轻点屏幕上的任意地洞，角色瞬移叩击；
- **方式二（虚拟手柄）**：左下角滑动摇杆控制走位，右下角大号红色锤击按钮（Hammer）击打。
