> **项目名称**：敲打！机器黄鼹鼠 · 马里奥聚会（Noggin Knock / ノコノコ・モグラたたき）

## 一、项目设计愿景与情感定位 (Vision & Identity)

### 1. 经典复刻与轻量化突围
在现代 Web 环境中，许多派对复刻游戏往往依赖 Phaser、PixiJS 或臃肿的资源包（动辄几十兆音视频、几百张图片），导致首屏加载慢、移动端发热、微信内打开卡顿。
本项目从立项之初就确立了**极简且硬核的原生工程路线**：
- **零外部资源请求**：不引入任何外部 `.mp3`、`.wav` 或第三方图片；
- **纯 Canvas 2D 硬件加速渲染**：利用原生数学与路径绘制，辅以微型矢量和程序纹理；
- **纯 Web Audio 物理算法合成**：所有挥锤、击扁、金币、爆炸、哨声均由代码实时通过振荡器和滤波器产生；
- **全端极速秒开**：无加载进度条，桌面端、平板、微信 H5 均能毫秒级加载。

### 2. 现代情绪价值：从“普通打地鼠”到“职场发泄解压舱”
传统打地鼠小游戏玩法单一、易产生疲劳感。本项目在复刻马里奥聚会经典机制的基础上，深度融入了**情绪投射与现代解压心理学**：
- 玩家不仅是在打机器黄鼹鼠，还可以自由将生活与工作中的痛点（如「加班」、「周一」、「Bug」、「甲方」）注入游戏；
- 目标带有醒目的靶心胶囊，被命中时触发暴击金币雨、大字体打击横幅与专属敲扁音效；
- 赛后自动生成专属的「今日发泄暴击战报」，给玩家带来从生理反应到心理释怀的双重情绪价值。

## 二、核心机制与空间立体建模 (Gameplay & Spatial Design)

```
       ┌────────────────────────────────────────────────────────┐
       │             背景光效与机械黄鼹鼠巨型吉祥物                │
       │                                                        │
       │    [上排 5 号洞]     [上排 6 号大王洞]    [上排 7 号洞]   │ (高阶梯·纵深高分点)
       │         ○                   ◎                  ○       │
       │ ────────────────────────────────────────────────────── │ (分界阶梯 Y=370)
       │    [0号]      [1号]      [2号]      [3号]      [4号]   │ (前排低层·高频快速点)
       │      ○          ○          ○          ○          ○     │
       │ ══════════════════════════════════════════════════════ │
       │                警戒条纹地台 & 玩家击打区域              │
       └────────────────────────────────────────────────────────┘
```

### 1. 双层阶梯立体舞台（8孔物理标定）
对齐 Switch 原版摄像机透视与舞台物理布局，精确校准为前 5 后 3 的立体 8 孔地洞阵列：
- **前排低层 5 洞（IDs: 0, 1, 2, 3, 4）**：
  - 呈弧线分布于前沿黄色地台（Y=422 附近），半径更平更宽，出入洞速度快，是连击与快节奏刷分的核心区。
- **后排高层 3 洞（IDs: 5, 6, 7）**：
  - 位于机械阶梯上层平台（Y=300~320），中央 6 号洞为“大王洞”（半径更大、得分更高）。
- **2.5D 深度遮挡与 Y-Sorting 排序**：
  - 传统 2D 打地鼠常出现角色踩在地洞上方却被地洞遮挡，或鼹鼠冒出时穿模的漏洞。
  - 本作实现了基于 Y 轴坐标的严格实时图层排序（Y-Sorting Render Pipeline）：
    `洞穴底槽 -> 鼹鼠/炸弹兵上升动画 -> 洞口金属圈遮罩 -> 角色马里奥及充气大锤 -> 击打特效粒子与金币飘字`。
  - 角色走到后排时被前排地洞平台遮挡，走到前排时自然遮住后排，展现强烈的空间立体感。

### 2. 双模式设计：休闲爽快 vs 全域竞技
为兼顾轻度手机单手用户与深度键盘竞技玩家，设计了无缝切换的两种核心模式：

| 维度 | 🕹️ 单排 5 洞极简模式 (5-Hole Front-Row) | 🎮 全域 8 洞标准模式 (8-Hole Full Arena) |
| :--- | :--- | :--- |
| **受众定位** | 手机端触控、碎片时间、高频解压、单手玩家 | PC 键盘党、手柄玩家、挑战极限反应的硬核用户 |
| **纵向约束** | **纵向坐标锁定（Y=370）**，严禁上下穿梭 | **全域自由纵深**（Y 轴自由移动，上下阶梯穿梭） |
| **横向移动** | 仅左右移动（← → 或 A / D 或摇杆左右） | 四向自由移动（↑ ↓ ← → 或 WASD 或摇杆 360°） |
| **刷新区域** | **严格过滤上排 3 洞**，仅在前排 5 洞高频出没 | 8 个洞穴全域随机冒出（含后排大王洞） |
| **精力消耗** | 精力集中度降低 70%，打地鼠节奏连贯度提升 200% | 需统筹全场走位与空间预判，策略性与操作上限更高 |

### 3. 三大出没物生物态系统
1. **机器黄鼹鼠（Mechanical Monty Mole）**：
   - 呆萌木质发条风格，带有金属门牙与发条钥匙转动动效；
   - 被锤击命中后触发瞬态扁平缩放（Y Scale 挤压至 0.2，X Scale 膨胀至 1.4），并附带眩晕蚊香眼与退回洞穴动效；
   - 命中奖励基础金币（+10 分）。
2. **定制发泄目标（Venting Target Mole）**：
   - 随机赋予玩家设定的标签（如「加班」、「周一」），头顶悬浮显眼的靶心红点胶囊；
   - 击扁后爆出专属强力音效、全屏震动、暴击金币（+50 分）以及【XXX 已被狠狠敲扁！】高亮战报横幅；
   - 计入赛后独立统计。
3. **黑火药炸弹兵（Bob-omb）**：
   - 随机点火出洞，头顶引线带火星颗粒与“滋滋”燃烧音效；
   - **高危避让惩罚**：玩家挥锤误击中炸弹兵会立即引发剧烈大爆炸，全屏震颤剧烈晃动，扣除 20 分，马里奥陷入短暂停顿硬直（黑脸眩晕）。

## 三、UI/UX 演进与移动端极致自适应 (UI/UX Evolution)

### 1. 从“双层冗余”到“双栏合一沉浸顶栏 (Unified Dynamic Glass Top Bar)”
* **旧版痛点**：顶部同时存在深黑底的全局系统栏（`top-bar`）与白底的屏幕内标题栏（`screen-header`），信息重复、视觉断层突兀，且纵向白白占用了近 110px 高度，导致手机端游戏画布被严重压缩、上下留出大黑边。
* **重构方案**：彻底消灭白底 `screen-header`，打造单层**深色高透毛玻璃沉浸顶栏**（`backdrop-filter: blur(16px)`，高度 52px / 移动端 48px）：

```
┌────────────────────────────────────────────────────────────────────────┐
│ [M] 敲打！机器黄鼹鼠   🕹️ [单排5洞]  ...  🪙 00  • 30   ▶ 开始  (🎯3)(🎮)(🔊) │
└────────────────────────────────────────────────────────────────────────┘
```

- **左侧品牌与模式区**：
  - **任天堂红底白字微型 [M] 徽标**：赋予经典纯正的马里奥 IP 视觉归属感；
  - **游戏主标题**：「敲打！机器黄鼹鼠」；
  - **模式切换胶囊**：采用深绿霓虹点缀，一键在「🕹️ 单排5洞」与「🎮 全域8洞」间自由切换，自带状态同步；
- **右侧常驻核心 HUD 与行动区**：
  - **🪙 金币数值胶囊**：金黄渐变高光，得分实时跳动递增；
  - **⏱️ 倒计时胶囊**：练习模式常驻显示，比赛时动态倒计并伴随低时间红光脉冲；
  - **▶ 开始主行动键**：马里奥红饱满渐变，一键开启 30 秒高能竞赛；
- **次级功能圆形收纳组**：
  - 发泄目标管理（🎯 带待敲扁目标数量红点徽标）；
  - 掌机外观切换（🎮/🖥️ 图标切换）；
  - 音效静音控制（🔊/🔇 图标切换）；
  - 统一收纳为一组紧凑半透明微型圆形磨砂按钮，主次层级分明，视觉绝不喧宾夺主。

### 2. 移动端极窄视口（375px~412px）响应式适配策略
针对 iPhone SE、Pixel 等各种极窄手机屏，采用外科手术级自适应调优：
1. **标题智能折叠**：在窄屏下自动隐藏长中文文本，保留精致立体的 [M] 徽标充当 App Icon；
2. **零占位弹性 HUD**：连击提示（`hudCombo`）在连击 ≤ 1 时采用 `display: none`，绝不占用常驻像素；
3. **尺寸微调与边距保护**：微调药丸边距与按钮内边距，确保左侧模式与右侧金币、计时、开始、3个次级图标在一行内自然舒展，**实现 0 换行、0 挤压、0 横向溢出**。

### 3. 全局纵向舒展与无黑边适配
去掉了上下冗余白条和脚手架栏后，游戏舞台纵向净赚 108px 以上空间。在 Pixel 7 视口实测中，游戏 Canvas 高度直接达到 **867px 纵向撑满**，彻底消灭了以往上下两道厚重的空黑条。

### 4. 双重交互方案：虚拟摇杆 + 屏幕直击 (Tap-to-Whack)
- **方案 A · 虚拟双摇杆（手柄党）**：
  - 屏幕左下角浮现半透明触控滑动摇杆（支持手指触摸跟随与阻尼回弹）；
  - 屏幕右下角配备醒目的马里奥红大号锤击按键（`btnHammer`，带 3D 阴影与微震动反馈）；
- **方案 B · 屏幕点哪打哪（Tap-to-Whack，触摸屏轻度党）**：
  - 玩家直接用手指轻点屏幕上的任意地洞，马里奥将瞬间位移至目标洞口并自动执行前向重锤叩击，极大提升了触控设备的游玩爽度与零学习成本。

## 四、纯原生 Web Audio 物理算法合成工程 (Audio Synthesizer)

为了做到零外部文件、零带宽等待并彻底规避移动端音频解码限制，本项目封装了完全基于浏览器底层 `AudioContext` 振荡器与滤波器的 `SoundEngine`：

```
                    ┌──────────────┐
                    │ AudioContext │
                    └──────┬───────┘
           ┌───────────────┼───────────────┐
           ▼               ▼               ▼
     [Oscillator]     [NoiseBuffer]   [BiquadFilter]
     (正弦/方波/三角波)  (白噪声发生器)   (低通/带通/高通滤波)
           │               │               │
           └───────────────┼───────────────┘
                           ▼
                     [GainNode] (指数包络 ADSR 衰减)
                           ▼
                    [Destination] (音频输出扬声器)
```

1. **充气大锤挥空声 (`playSwing`)**：
   - 采用 0.15 秒带通滤波器扫描的白噪声源（400Hz -> 1200Hz -> 200Hz 指数拉升与下坠），精确模拟重锤破风的呼啸声。
2. **橡胶击扁橡皮声 (`playHitMole`)**：
   - 快速下潜的方波基频（280Hz -> 60Hz，0.12秒内），叠加瞬时失真低通滤波，还原玩具橡胶锤击打塑料鼹鼠特有的“啾噗！”弹性质感。
3. **炸弹兵引线火星声 (`playFuse`)**：
   - 周期性调制的微脉冲高通粉红噪声，形成“嘶嘶——滋滋——”的急促燃烧临场感。
4. **炸弹爆炸巨响 (`playExplosion`)**：
   - 低频重低音（50Hz）正弦波瞬时下潜冲击，并联由强失真增益放大的白噪声猝发，伴随全屏剧烈摇晃。
5. **金币清脆叮当声 (`playCoin`)**：
   - 纯正正弦波高频双音阶（B5 987.77Hz 延展至 E6 1318.51Hz），带金属清脆回响。
6. **程序化派对 BGM (`startBGM`)**：
   - 128 BPM 嘉年华轻快节拍，由代码根据步进节拍动态合成方波贝斯走带与欢快乐段，无需外部背景音乐文件也能营造热烈的马里奥聚会派对气氛。

### 2. 核心状态机 (FSM) 运转流
```
  [进入页面]
      │
      ▼
┌──────────────┐      点击 [▶ 开始]      ┌─────────────────┐
│ STATE_PRACTICE│ ──────────────────────► │ STATE_COUNTDOWN │
│ (自由练习模式) │                         │ (3-2-1-GO 倒计时)│
└──────────────┘                         └────────┬────────┘
      ▲                                           │ 倒计时结束
      │                                           ▼
      │ 再来一局 / 重新练习               ┌───────────────┐
      └────────────────────────────────── │ STATE_PLAYING │
                      比赛结束 (0秒)       │ (30秒激烈竞技) │
                      ┌─────────────────► └───────────────┘
                      │
              ┌───────┴────────┐
              │ STATE_GAMEOVER │
              │ (战报结算与评分)│
              └────────────────┘
```

### 3. 关键性能与内存守护
- **粒子对象池与轻量化回收**：击中产生的金币粒子、浮动伤害字体在离开视口或透明度为 0 时立即移出活跃数组，保持内存平稳，绝无泄漏；
- **自适应 DPI 物理渲染（DevicePixelRatio Scaling）**：
  - 视网膜屏幕（Retina / 高刷屏）根据 `window.devicePixelRatio` 动态设置内部 Canvas 缓冲区分辨率，并在 CSS 中限制显示尺寸，确保画面极致锐利清晰且不产生额外渲染负担；
- **离屏防闪烁与平滑阻尼**：摄像机震动通过衰减因子 `shakeDuration *= 0.9` 指数退火，视觉冲击力强烈且过渡平滑。

## 七、未来演进路线 (Future Roadmap)

1. **本地多人双人同屏对决**：利用左右虚拟摇杆或键盘分键（WASD + J vs 方向键 + Enter），在同一块屏幕上开展 1v1 抢洞对决；
2. **更多经典派对道具出没**：
   - **黄金无敌星**：短暂时间内挥锤速度提升 100%，移动速度翻倍；
   - **时钟蘑菇**：所有鼹鼠在空中悬停 3 秒，提供割草般连击快感；
3. **战报长图一键生成**：在比赛结束时，通过离屏 Canvas 一键生成带印章的拍立得复古风格战绩海报，支持手机端长按一键保存到系统相册并分享到微信朋友圈。
