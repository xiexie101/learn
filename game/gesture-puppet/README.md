# 手势表情木偶 (Gesture Puppet)

这是一个基于 Web 摄像头手势识别的轻量级互动小应用。通过不同的手指数量，你可以控制屏幕中央木偶的表情，并且它会一直“盯着”你的手看！

## 功能特点
- 🖐️ **手势识别**：基于 MediaPipe Hands，实时识别你伸出的手指数量 (0-5)。
- 🎭 **表情联动**：不同手指数量对应不同的 Emoji 表情和状态。
- 🗣️ **语音反馈**：利用 Web Speech API，在表情切换时自动播放对应的音效/语音。
- 🌀 **3D 跟随动效**：通过捕捉手掌中心坐标，木偶会在 3D 空间内实时旋转，产生“盯着手看”的视觉效果。

## 如何运行
无需复杂的环境配置。由于浏览器对调用摄像头的安全限制，你需要在一个本地服务器环境下运行它。

你可以使用 Python 自带的 HTTP 服务器启动：
```bash
cd gesture-puppet
python -m http.server 8000
```
然后打开浏览器访问：`http://localhost:8000`

## 交互说明
- 允许浏览器使用摄像头。
- 点击“开始互动”按钮进入主界面。
- 将手置于摄像头前：
  - **0 指 (握拳)**：睡觉 😴 (呼呼呼)
  - **1 指**：平静 😐 (嗯)
  - **2 指**：微笑 😊 (嘿嘿)
  - **3 指**：大笑 😂 (哈哈哈)
  - **4 指**：惊讶 😱 (啊？)
  - **5 指**：兴奋 🤩 (哇哦！)

*注意：识别时请尽量将手掌正面或背面完全展露在镜头前，以便更准确地识别手指弯曲状态。*
