# 🖋️ INKFALL · 墨水雨 (Three.js 复刻版)

> **“墨水雨：一款用圆珠笔绘制的火柴人射击游戏，敌人会爆裂成五彩缤纷的颜料。你可以跳上笔记本塔，在子弹中空中冲刺，最终面对长着翅膀的墨水之神。”**

## 🎨 核心美学与设计原则 (Aesthetics & Juiciness)

1. **圆珠笔笔记本美学 (Ballpoint Pen Notebook Style)**:
   - 浅米黄微暖复古稿纸底色 (`#f8f6f0`)，淡蓝横向横线与浅灰网格坐标，左侧红色装订页边线。
   - 笔触微抖动与压感仿真：角色与机关采用有机贝塞尔曲线与微随机抖动渲染，呈现停格动画般的真实手绘翻页质感。
   - 结构平台：经典 45° 蓝色笔触斜向排线阴影 (`//////`) 与底部三角支撑桁架。
   - 致命陷阱：红笔手绘交叉锯齿网纹 (`#dc2626`)。

2. **强对比五彩颜料爆裂 (Gouache / Acrylic Splatter Burst)**:
   - 蓝红双色草稿纸世界中，当敌人与 Boss 被击中或爆裂时，迸发出极为鲜艳厚重的水粉颜料（品红 `#ff2d75`、青天蓝 `#00f0ff`、鲜柠檬黄 `#ffde00`、橙色 `#ff6b00`、翡翠绿 `#10b981`、罗兰紫 `#a855f7`）。
   - **真实颜料附着物理 (Paint Decals on Paper)**：溅射的油彩不仅在空中飞扬，撞击到笔记本平台或地面时会永久粘附浸染，形成彩色水粉水渍，战况越激烈，笔记本纸页越绚烂！

3. **双轨关卡与墨水之神 (Ascent & The Hollow Saint Boss)**:
   - **攀登塔 (0m ~ 300m)**:
     - `01 / THE ROOTS (0~100m)`：基础跑跳与初遇红色狙击手、旋转符文核心。
     - `02 / THE VERTICALS (100~200m)`：狭窄竖井滑墙跳（Wall Jump）与高空跳跃。
     - `03 / THE SKYBRIDGES (200~300m)`：浮空天桥大群敌人与狙击连线。
   - **大圣堂神战 (Summit / The Cathedral 300m+)**:
     - 机械/羽翼神像 **空心圣徒 (The Hollow Saint)** 降临！
     - 阶段一 `BOUND I`：双翼扫射、光环符文弹幕与穿透投枪。
     - 阶段二 `UNBOUND II (THE HALO BREAKS)`：光环碎裂为轨道飞刃，地面化为红笔尖刺禁区（The floor is no longer safe），必须全程滞空踩踏浮台与空中冲刺。
     - 阶段三 `APOCALYPSE III (NO MORE MERCY)`：终焉弹幕狂潮，红色禁忌狂暴，超载爆发！
     - 终局斩杀：`GOD IS JUST A DRAWING. And you brought an eraser.`（神只是一幅画，而你带来了橡皮擦），全屏五彩斑斓极光颜料大爆炸！

## 🕹️ 交互体验与全键位支持

| 操作 | 键盘按键 | 触控 / 鼠标交互 | 特殊机制 |
| :--- | :--- | :--- | :--- |
| **移动 / 转向** | `A` / `D` 或 `←` / `→` | 虚拟摇杆 (左下角圆盘) | 具有惯性与摩擦阻尼 |
| **跳跃 / 滑墙跳** | `W` / `↑` / `Space` | 右下角 `JUMP` 按钮 | 支持两段跳；靠墙滑行时按跳跃触发蹬墙跳 |
| **下蹲 / 穿台** | `S` / `↓` | 摇杆下拉 | 蹲伏穿过低矮障碍 |
| **空中冲刺 (Dash)** | `Shift` / `右键` / `K` | 右上角 `DASH` 按钮 | **子弹反弹 (Dash sends bullets back)**：冲刺瞬间可弹反敌弹转化为高伤彩弹！着地或触墙即可重置冷却 (`LAND / REFILL` -> `DASH READY`) |
| **子弹时间 (Focus)** | `F` / `L` | 左上角 `FOCUS` 按钮 | 降低 72% 时间流速，精准规避密集弹幕并引导弹反 |
| **射击 (Ripper)** | `左键` / `J` / 空格 | 左下角 `FIRE` 按钮 | 支持自动连发 (AUTO) 与手动点射切换 |
| **超载爆发 (Surge)** | `E` / `Q` | 点击底部 `SURGE` 槽 | 积蓄满后触发 6 秒多重散射暴击暴雨 |

## 🔊 原生声学系统 (Zero-Asset Web Audio API)

无需加载任何外部 MP3/WAV 资源，秒级自启动：
- **圆珠笔摩擦音 (Pen Scratch)**：走动、落地、滑墙时的真实纸面划线砂纸感白噪声带通滤波。
- **按压笔清脆回弹音 (Pen Click)**：双脉冲机械按簧回弹声。
- **弹反清脆叮声 (Deflect Ping)**：高频金属笔尖敲击振鸣。
- **湿润颜料溅泼声 (Wet Splat)**：敌人爆裂时的液态气泡共鸣水粉啪溅声。
- **自适应动态配乐 (Adaptive BGM)**：
  - 攀爬阶段：轻快的铅笔节奏打底与走音贝斯。
  - 大圣堂神战阶段：管风琴圣歌和弦与厚重合成器琶音，阶段二与阶段三动态升调增强压迫感！
