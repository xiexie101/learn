## ✨ 核心特色与惊喜设计

1. **沉浸式办公室敲门开场**：
   - 复古木质办公室大门与“三年级数学组·班主任闭关室”铜牌；
   - 互动轻敲 3 下房门，“吱呀”推门进入，仪式感拉满。
2. **Q版头像解压戳戳乐**：
   - 右上角常驻带博士帽的老师头像，随时点击触发果冻弹跳与微触觉震动；
   - 冒出丰富解压气泡（班主任日常梗 + 数学极客梗，如*“默念：是亲生的……”*、*“今天不解方程只解压”*）。
3. **班主任精神状态防御战（3大奇葩关卡）**：
   - 关卡 1：【消失的数学作业】小神兽哭诉作业被狗嚼烂了；
   - 关卡 2：【进水与排水的哲学】经典应用题遭灵魂反问“管理员是不是闲得慌”；
   - 关卡 3：【下班前的夺命1分钟】背包已收拾好，又有神兽来告状被踩了影子。
   - 提交选择后触发经典的“红笔打大红勾”与爆笑反转评语！
4. **终极通关盛典**：
   - **超出实数集定义范围的成绩**：评分 $+\infty$ 分；
   - **满屏彩色学生弹幕**：漫天飞过小学生可爱的童言童语与节日祝福；
   - **互动续命奶茶**：点击吸管咕咚咕咚喝奶茶，液面下降，珍珠晃动；
   - **老友手写长信**：真诚走心、懂她的辛苦与坚守。
5. **教师节专属“心愿护身符”刮刮乐**：
   - 真实仿真银色涂层刮刮乐，手指涂抹擦除；
   - 随机揭晓【拖堂免疫符】、【静音结界符】、【发量茂密符】等神仙好运！
6. **一键生成朋友圈战报海报**：
   - 纯前端 Canvas 现场合成拍立得风格的“2026教师节·战报勋章”；

7. **纯原生零依赖**：
   - 单文件 HTML/CSS/JS，Web Audio 实时音频合成，微信/浏览器秒开无等待。

## 🛠️ 如何极简个性化配置（只需 10 秒）

打开 `index.html`，在第 **1146 行左右**（或搜索 `CONFIG`）找到配置块即可直接修改：

```javascript
const CONFIG = {
  // 1. 老师称呼与你的署名
  teacherName: "陈老师",               // 改成她的真实称呼（如“王老师”、“陈陈”）
  friendName: "世锦 / 你的老铁",        // 改成你的真实名字或署名
  schoolSubject: "小学数学",           // 任教学科（如“小学数学”、“三年级语文”）
  doorTitle: "三年级数学组",          // 门牌文字

  // 2. 真实头像
  // 直接把她的一张美照命名为 avatar.jpg 放在本目录下即可！
  avatarUrl: "./avatar.jpg",

  // 3. 自定义奶茶名称
  milkTeaName: "班主任续命·全糖多肉葡萄",

  // 4. 自定义手写长信内容
  letterContent: `亲爱的陈老师：
……（在此填写你想对她说的真心话）……`
};
```
