## 二、主角形象与头像交互设计

- **头像挂件呈现**：
  - 屏幕右上角常驻圆圆的老师大头贴，头戴金色立体学士帽（博士帽），带Q弹果冻动画与发光投影。
  - **优雅降级机制**：代码中内置精美手绘女老师矢量 SVG 兜底；只需在同级目录放入 `avatar.jpg` 即可 1 秒自动替换为她的真实美照。
- **解压戳戳乐机制**：
  - 任意时刻点击/戳戳头像，头像触发弹跳缩小回弹，并冒出解压文字气泡；
  - 配备连击计数（Combo Badge，如 `x1`, `x2`, `x3`...）；
  - 触发手机微触觉震动反馈（`navigator.vibrate(15)`）；
  - **解压气泡词库**（班主任日常梗 + 数学极客梗）：
    1. *“默念：是亲生的，是亲生的……💆‍♀️”*
    2. *“血压+1，但情绪依旧保持端庄优雅 ☕”*
    3. *“今日耐心余额：已透支，需大杯奶茶续命 🧋”*
    4. *“已知：今天过节；求证：必须快乐；证明：显然成立！📐”*
    5. *“今天不解一元一次方程，只负责解压～✨”*
    6. *“心平气和，像平行线一样永远不跟捣蛋鬼产生交集 📏”*
    7. *“世界如此美妙，我不暴躁，我很高尚 🧘‍♀️”*
    8. *“超出实数集定义范围的优秀！💯”*
    9. *“别慌！距离打铃放学还有最后一点点！🏃‍♀️”*
    10. *“今天谁敢拖堂？老师第一个不同意！🎉”*

## 三、沉浸式开场与关卡设计

### 1. 办公室“敲门”沉浸开场 (建议 4)
- **视觉**：复古木门质感，悬挂【三年级数学组·班主任闭关室】金属铜牌；
- **告示牌**：*“📝 告示牌：今日教师节！拒绝批改作业，只想早点下班！”*；
- **交互**：提示“轻敲 3 下房门，拯救班主任”，每次敲门带浑厚敲击音效、微震动和门板微转动；敲满 3 次门板向内打开，彩光涌出转入黑板答题区。

### 2. 班主任精神状态模拟器（3大关卡）
每个关卡均取材于小学老师最真实、最哭笑不得的突发状况，选定答案后触发**红笔“唰——”打大红勾**动画：

* **第一关【早读突发：消失的数学作业】**
  * *情境*：小神兽哭诉作业被家里小狗嚼得稀烂吃进肚子了。
  * *选项 A*：“拿来让我闻闻，到底有没有小狗口水味？”（小神兽眼神飘忽心虚后退）
  * *选项 B*：“明天把你家这只爱吃算术题的学霸神犬带到讲台替你听课！”（全班爆笑）
  * *选项 C*：“没关系，老师抽屉里刚好有一本全新加厚典藏版，拿去重新写吧。”（小神兽瞳孔地震）
* **第二关【上午课堂：进水与放水的宿命哲学】**
  * *情境*：经典应用题“一个水管进水一个水管放水”，小神兽举手反问“管理员是不是闲得慌”。
  * *选项 A*：“他不是闲，他是在用自己的一生给全国小学生编算术题！”（全班雷鸣般掌声）
  * *选项 B*：“问得好！今晚留下来你来当管理员，拿吸管把多出来的水给我喝光！”（小神兽乖巧捂嘴）
  * *选项 C*：“在数学的宇宙里，没有无缘无故的水流，只有想测出你们智商上限的老师。”（投来哲学家的崇拜目光）
* **第三关【傍晚下班：放学前的夺命绝杀1分钟】**
  * *情境*：距离17:00下班还剩5秒，两只小神兽冲进来哭诉“他故意踩我影子，影子疼哭了”。
  * *选项 A*：“科普时间：根据光的直线传播，踩到影子的概率为100%，无罪释放！”（几何光学光速结案）
  * *选项 B*：“光速判决：现在闭上眼睛，谁先睁开眼睛谁留下来互相擦黑板！”（两神兽石化不敢眨眼）
  * *选项 C*：“老师要施展数学移形换影大法了，明天早自习再审影子案！”（瞬移校门口奶茶店）

## 四、终极通关盛典与情感升华

### 1. 评分与礼花
- **结算战绩**：打出 **$+\infty$ 分（正无穷）**，称号为【特级情绪管理大师 · 宇宙无敌神仙老师】。
- **全屏彩带**：Canvas 实时喷射 60+ 颗五彩纸屑彩带粒子。
- **满屏彩色弹幕**：学生童言童语飘屏（“祝X老师教师节快乐”、“数学课最喜欢听你讲段子”、“全校最飒数学班主任”）。

### 2. 交互式“续命奶茶”
- 屏幕中央呈现立体奶茶杯与吸管（“班主任专属续命大杯 · 老友特供全糖去冰多肉葡萄”）；

### 4. 教师节专属“心愿护身符”刮刮乐 (重点新增)
- 真实银色涂层刮刮卡，手指/鼠标滑动涂抹擦拭；
- 随机揭晓以下三道神仙好运之一：
  1. 🎴 **【拖堂免疫神符】**：下课铃响瞬间刚好讲完最后一题，全学期零拖堂，下班步速全校第一！
  2. 🎴 **【静音结界神符】**：踏入教室刹那，几十只小神兽自动安静如绵羊，全班乖巧听讲！
  3. 🎴 **【发量茂密神符】**：任凭批改几百本作业练习册，发量依然如瀑布般蓬松浓密！

### 5. 朋友圈专属战报海报生成器 (建议 2)
- 点击【生成朋友圈专属战报海报】按钮；

## 五、个性化配置规范 (`CONFIG`)

所有业务文本、图片与个性化信息均收敛于 `index.html` 的 `CONFIG` 对象中：

```javascript
const CONFIG = {
  teacherName: "X老师",               // 老师尊称（支持直接修改）
  friendName: "你的老铁/好友",          // 你的署名
  schoolSubject: "小学数学",           // 任教学科
  doorTitle: "三年级数学组",          // 办公室门牌
  avatarUrl: "./avatar.jpg",         // 真实头像路径（支持本地相对路径或远程图床）
  milkTeaName: "班主任续命·全糖多肉葡萄", // 奶茶品名
  letterContent: "...",              // 手写长信内容
  bubbleQuotes: [...],               // 戳戳乐随机气泡词库
  talismans: [...],                  // 护身符候选池
  danmakus: [...]                    // 学生彩色弹幕列表
};
```
