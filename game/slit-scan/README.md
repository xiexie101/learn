# Slit-Scan 狭缝扫描照相馆 📸

> 像素级完美复刻自 [letsscan.club/scan/](https://letsscan.club/scan/) 的平床狭缝扫描体验。

## 🌟 核心特性

- **双画布平床扫描引擎**：
  - 左侧扫描床（Scan Bed）：支持鼠标拖拽位移、滚轮无级缩放（0.1x ~ 4.0x）、移动端单指平移与双指捏合缩放。
  - 动态红外激光线：由白色核心线（2px）与红外光晕渐变（16px）构成，随扫描速度平滑垂直下行。
  - 右侧成像预览（Slit-Scan Output）：采用子像素 Lerp 插值平滑算法，在激光逐行掠过时实时抽取单像素切片，生成极具艺术感的形变拉伸与时间重构效果。
- **高定视觉与复古质感**：
  - 100% 还原的复古网格毫米信纸底色（`#E0E8D5`）与淡青色结算底色（`#D5E4E8`）。
  - 原生内嵌的 `Inktoner` 粗衬线雕版标题字体。
  - 定制像素矢量手势光标（Grab / Grabbing 抓取触感）。
- **完整交互生态**：
  - **更换图片**：一键更换本地任意图片，自动智能适配居中比例。
  - **速度变速调节**：1~6 档逐级平滑调速弹层。
  - **清空画布**：一键重置清空右侧预览。
  - **完成结算工作台**：由 GSAP 驱动的丝滑出场动效。
  - **涂鸦画板**：自由选取画笔颜色、底色置换、画笔粗细调节（1~40px）与橡皮擦功能。
  - **下载保存**：合并涂鸦图层，无损导出 1200x1500 超清 PNG。
  - **存入画廊**：100% 本地浏览器沙箱持久化存储，无需任何网络外发。
- **全端响应式与无缝入口**：
  - 桌面端：宽屏沉浸式左右对开视窗与手绘涂鸦视差着陆页。
  - 移动端：智能堆叠布局，适配各类触屏手势。

## 🚀 运行与体验

在项目根目录下启动静态服务器，或在浏览器中直接打开 `index.html`：

```bash
# 启动本地服务
python3 -m http.server 8765 --directory webapp/slit-scan
```

访问 `http://localhost:8765/` 即可进入着陆页，点击「开始全新扫描 →」即可进入扫描工作台。
