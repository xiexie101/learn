# StitchCraft · 拟真手工刺绣创作工坊 🧵

> **Turn Ideas Into Stitches** —— 极致拟真的手工刺绣模拟与数字手工艺创作 Web 应用。

---

## 📖 项目简介

`StitchCraft` 是一款高度拟真、手感细腻的数字化手工刺绣设计工坊。通过物理纹理生成算法、多层 Canvas 渲染管线与动态针刺动效，在浏览器端还原了指尖穿针引线的传统刺绣质感。

---

## ✨ 核心特性

### 1. 🧵 7 种经典刺绣针法引擎
- **平针 (Running Stitch)**：基础虚线行针，适合勾勒轮廓与虚线装饰。
- **回针 (Back Stitch)**：连续密实线迹，经典轮廓与细腻写实线条。
- **十字绣 (Cross Stitch)**：传统 X 形十字绣花纹，支持网格对齐辅助。
- **锁链绣 (Chain Stitch)**：环环相扣的链式线环质感，立体感强。
- **缎面绣 (Satin Stitch)**：密集平行的丝缎光泽填充，适合色块平铺。
- **法国结 (French Knot)**：小巧立体的颗粒点缀，适合花蕊、眼睛与细节质感。
- **雏菊绣 (Lazy Daisy)**：花瓣状线圈环，一笔呈现自然花瓣与叶片。

### 2. 🪡 物理感交互与下沉动效
- **真实运针指示**：指针跟随画笔姿态旋转倾斜，还原执针与刺入布面的物理反馈。
- **针目下沉 (Settling Animation)**：落针后线迹动态收缩微沉入布面，配合光影阴影形成真实立体刺绣质感。
- **颜色吸管 (Eyedropper)**：点击绣布上已存在的线迹，快速提取线程配色。

### 3. 🌾 织物布纹生成管线
- **亚麻画布 (Linen Fabric)**：自适应经纬织线凹凸纹理、纤维微杂色与边缘布边毛圈细节。
- **多层渲染架构**：
  - `stage__fabric`：底层布纹纹理层（渐进式双倍采样生成）。
  - `stage__stitches`：线迹矢量渲染与离屏缓存合并。
  - `stage__overlay`：交互手势层（运针动效、辅助网格、橡皮擦范围、实时线迹预览）。

### 4. 🎨 调色盘与参数控制
- **精选色盘**：13 种传统手工艺染线配比（包含本白、麦芽、鹅黄、蜜橘、落霞、茜红、青丁香、水蓝、孔雀青、青草、枯茶、棕褐、烟墨）。
- **参数微调**：
  - 针脚长度 (Stitch Length: 4px ~ 24px)
  - 丝线粗细 (Thread Thickness: 1px ~ 8px)
  - 经纬对齐网格 (Show Grid)

### 5. 📁 模板、存储与多种导出格式
- **内建典范模板**：经典复古机器人、扬帆起航小舟、森林木屋等丰富刺绣预设。
- **本地持久化**：基于 `IndexedDB` 本地实时保存工程，支持 `Ctrl/Cmd+S` 快捷键。
- **全格式导出**：
  - `PNG image 1x`：标准光栅预览图
  - `High resolution PNG 3x`：高精印刷级布纹与线迹细节图
  - `Project JSON`：完整线迹矢量点位与参数工程文件，支持导入继续编辑

## ⌨️ 快捷键速查

| 快捷键 | 功能 |
| :--- | :--- |
| `1` ~ `7` | 快捷切换 7 种刺绣针法 |
| `Space` + 拖拽 | 抓手平移画布 (Pan) |
| `Ctrl / Cmd + Z` | 撤销 (Undo) |
| `Ctrl / Cmd + Shift + Z` 或 `Ctrl + Y` | 重做 (Redo) |
| `Ctrl / Cmd + S` | 保存至当前浏览器存储 |
| `鼠标滚轮 / 双指缩放` | 无级缩放画布视图 |

## 🛠️ 技术栈与架构

- **前端核心**：React 18、原生 Canvas 2D API、Web Context API
- **状态与历史管理**：自研轻量级 Store 与 Command Pattern 撤销重做栈
- **持久化**：原生 `IndexedDB` 异步对象存储
- **响应式视口**：ResizeObserver + DPR 双向自适应变换矩阵
- **单文件交付**：零外部依赖打包，无需构建工具即可离线全功能运行
