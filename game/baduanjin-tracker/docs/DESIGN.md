# 八段锦每日运动追踪器 - 设计方案
*传统养生 · 现代科技 · 智能追踪*

## 🎨 整体设计理念

### 设计哲学
- **传统与现代融合**: 中国传统养生文化与现代扁平化设计的完美结合
- **宁静致远**: 营造平和、专注的练习氛围
- **游戏化激励**: 通过视觉反馈和成就系统增强用户粘性
- **数据可视化**: 让进步看得见,让坚持更有动力

---

## 🌸 禅意花园系统 (Zen Garden System)

### 设计理念

**核心隐喻**: 将用户的练习历程比喻为培育一座禅意花园,从荒芜到繁茂的过程象征着从初学到精通的修行之路。

**设计原则**:
- **非竞争性**: 关注自我成长,而非与他人比较
- **叙事驱动**: 通过视觉化的成长故事增强情感联系
- **文化契合**: 与八段锦的静心、平衡理念完美融合
- **渐进式奖励**: 每个阶段都有可见的进步和惊喜

### 花园成长体系

#### 等级与花园元素对应关系

```
Lv.1 初学者 (0-7天)    → 🪨 荒芜石地 (Starting Stone)
Lv.2 入门 (8-21天)     → 🌿 青苔初现 (Moss Appears)
Lv.3 熟练 (22-50天)    → 🌱 嫩草萌发 (Young Grass)
Lv.4 精通 (51-100天)   → 🌊 清池涟漪 (Tranquil Pond)
Lv.5 专家 (101-200天)  → 🪷 莲花绽放 (Lotus Blooms)
Lv.6 大师 (201-365天)  → 🐟 锦鲤游弋 (Koi Swimming)
Lv.7 宗师 (365+天)     → 🌳🏮 树木石灯 (Trees & Stone Lantern)
```

#### 花园视觉演变

**阶段一: 荒芜石地** (Lv.1)
```
视觉描述:
- 灰褐色的石头散落在空地上
- 简约的禅意构图
- 细腻的沙纹(枯山水风格)
- 色调: 灰、褐、米白
```

**阶段二: 青苔初现** (Lv.2)
```
视觉描述:
- 石头上开始长出绿色青苔
- 苔藓随练习天数逐渐扩散
- 增添生机感
- 色调: 灰褐 + 墨绿
```

**阶段三: 嫩草萌发** (Lv.3)
```
视觉描述:
- 地面长出细嫩的小草
- 草地面积随进度扩大
- 微风吹拂的动画效果
- 色调: 嫩绿 + 翠绿
```

**阶段四: 清池涟漪** (Lv.4)
```
视觉描述:
- 出现一个小型池塘
- 水面有细微的波纹动画
- 倒映天空和周围景物
- 色调: 碧蓝 + 翠绿
```

**阶段五: 莲花绽放** (Lv.5)
```
视觉描述:
- 池塘中长出莲花
- 莲花从花苞到盛开的动画
- 荷叶随风摇曳
- 色调: 粉红 + 碧绿
```

**阶段六: 锦鲤游弋** (Lv.6)
```
视觉描述:
- 池塘中出现锦鲤
- 锦鲤缓慢游动的动画
- 水面涟漪互动效果
- 色调: 橙红 + 金色
```

**阶段七: 树木石灯** (Lv.7 - 修行圆满)
```
视觉描述:
- 花园边缘长出松树/樱花树
- 出现传统石灯笼
- 完整的禅意花园景观
- 四季变化效果(可选)
- 色调: 丰富多彩,和谐统一
```

### 千里江山图变体 (可选方案)

**概念**: 用户的练习历程如同徐徐展开一幅《千里江山图》长卷

**实现方式**:
- 初始: 只显示画卷的一小部分(远山轮廓)
- 每次练习: 画卷向右展开一段
- 里程碑: 解锁画卷中的重要景观(瀑布、亭台、舟船)
- 完成一年: 完整的千里江山图全景

**优势**:
- 更具中国传统艺术美感
- 线性的进度可视化
- 适合横向滚动展示

**劣势**:
- 技术实现较复杂
- 需要高质量的美术资源
- 移动端展示受限

**建议**: 作为高级解锁主题,在用户达到大师等级后提供

### 技术实现方案

#### 花园渲染技术

**方案一: SVG 动画** (推荐)
```html
<svg viewBox="0 0 800 600" class="zen-garden">
  <!-- 背景层 -->
  <rect class="garden-bg" />
  
  <!-- 池塘层 -->
  <ellipse class="pond" />
  <g class="water-ripple">
    <circle class="ripple" />
  </g>
  
  <!-- 植物层 -->
  <g class="lotus">
    <path class="lotus-leaf" />
    <path class="lotus-flower" />
  </g>
  
  <!-- 动物层 -->
  <g class="koi">
    <path class="koi-body" />
    <animateMotion dur="5s" repeatCount="indefinite">
      <mpath href="#koi-path" />
    </animateMotion>
  </g>
</svg>
```

**优势**:
- 矢量图形,无限缩放
- CSS/SMIL动画支持
- 文件体积小
- 易于交互

**方案二: Canvas 动画**
```javascript
class ZenGarden {
  constructor(canvas) {
    this.ctx = canvas.getContext('2d');
    this.elements = [];
    this.animate();
  }
  
  addElement(type, level) {
    // 根据等级添加花园元素
  }
  
  animate() {
    // 渲染循环
    requestAnimationFrame(() => this.animate());
  }
}
```

**优势**:
- 性能更好
- 复杂动画支持
- 粒子效果易实现

**方案三: CSS + HTML** (简化版)
```css
.zen-garden {
  position: relative;
  background: linear-gradient(to bottom, #E8F5E9, #FFF8E1);
}

.garden-element {
  position: absolute;
  transition: all 0.5s ease;
}

.koi {
  animation: swim 5s infinite;
}

@keyframes swim {
  0%, 100% { transform: translateX(0); }
  50% { transform: translateX(100px); }
}
```

**优势**:
- 实现简单
- 兼容性好
- 易于维护

**推荐**: 初期使用方案三,后期升级到方案一
