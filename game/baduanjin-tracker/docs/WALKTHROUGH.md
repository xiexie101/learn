# 八段锦每日运动追踪器 - 项目交付文档

## 🎉 项目概览
恭喜! 您的**八段锦每日运动追踪器**已开发完成。这是一个融合了传统养生理念与现代Web技术的渐进式Web应用(PWA)。

### 核心功能
1.  **每日打卡**: 轻松记录八段锦八式练习进度。
2.  **禅意花园**: 随着您的坚持，荒芜的石地将逐渐演变成繁茂的禅意花园(SVG动画)。
3.  **音效反馈**: 内置Web Audio合成的木鱼声和钟声，无需外部资源。
4.  **成就系统**: 追踪连击、等级和特殊里程碑，解锁精美徽章。
5.  **月度日历**: 直观查看每月的练习历史。
6.  **离线可用**: 支持PWA，安装到手机后可离线使用。

## 🚀 如何运行
由于这是一个纯静态Web应用，您可以通过以下方式运行：

1.  **直接打开**: 双击 `index.html` 在浏览器中打开。
2.  **本地服务器** (推荐):
    ```bash
    cd /Users/xieshijin/jin/learn/ai/baduanjin-tracker
    python3 -m http.server 8000
    ```
    然后访问 `http://localhost:8000`。

## 📱 移动端体验
您可以将此应用添加到手机主屏幕，获得类似原生应用的体验：
1.  在手机浏览器打开应用。
2.  点击"分享" (iOS) 或 "菜单" (Android)。
3.  选择"添加到主屏幕"。

## 📂 文件结构
- `index.html`: 应用入口
- `css/`: 样式文件 (variables.css, styles.css)
- `js/`: 逻辑文件
    - `app.js`: 主控制器
    - `data.js`: 数据存储与配置
    - `garden.js`: 禅意花园渲染引擎
    - `sound.js`: 音效合成引擎
    - `calendar.js`: 日历组件
- `sw.js` & `manifest.json`: PWA支持文件

## 🎨 视觉与交互
- **动态花园**: 尝试点击花园中的元素(如水面)，会有互动效果。
- **等级系统**: 坚持练习，您的等级将从"初学者"一路晋升至"宗师"。
- **设置**: 点击右上角齿轮图标，可以开关音效或重置数据。
