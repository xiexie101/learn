# 🏛️ 看见中国之美 · 全年54件国宝与数字日晷 (2027 人文台历)

> **一年 54 次与中国之美相遇 —— 桌面级古代艺术图谱、数字赤道日晷与立体文博有声展厅**

---

## 📖 项目简介

**「看见中国之美」** 是一款基于纯原生前端技术构建的文博美育数字台历与案头艺术展厅应用。项目以故宫与各省市重点博物馆珍藏的 **54 件国宝重器** 为时空坐标，从第 00 周的西汉托克托日晷出发，横跨新石器时代彩陶、商周吉金、汉唐书画、宋元瓷器与明清古建，构建了一座装在浏览器里的微型中国古代艺术博物馆。

应用搭载了 **高保真数字赤道日晷时钟**、**3D 拟真物理翻折双面卡片**、**文博专家原声有声导览与逐段台本字幕联动**、**多维地域省份/月份/门类立体筛选**、**全年 54 国宝图鉴打卡护照**，以及 **1080 × 1920 手机高清壁纸实时渲染工坊**。

---

## ✨ 核心功能与亮点

### 1. 🕰️ 光阴流转 · 案头数字赤道日晷引擎
- **汉代托克托日晷原器复现**：以西汉边塞重镇云中郡出土的“百刻制”赤道石日晷为设计蓝本，四角雕刻柿蒂纹；
- **晨昏光影交互滑块**：支持手动拖动晨昏滑块，实时模拟 24 小时太阳入射角变化与晷针日影长度流转；
- **岁时时钟与时空罗盘**：外圈动态对应 24 节气与 54 周岁时，内圈精准联动十二时辰地支刻度，与真实系统时钟实时同步；
- **声效联动**：支持开启或收起日晷展开面板，体验仪式感十足的案头时光测度。

### 2. 🎴 3D 双面拟真特种纸国宝卡片
- **正面 · 展陈级真迹展台**：
  - **54 张超高清真迹全画幅展陈**：采用 `object-fit: contain` 配套底层同图高斯模糊光晕与艺术暗角，兼顾全景视野与材质细节，绝无暴力拉伸或裁切；
  - **多维文博徽章**：清晰标注文物所属年代朝代、馆藏博物馆、核心省份与艺术分类（百工、金石、古建、书画、造像、壁画）；
  - **策展金句名言**：每件国宝配有直击心灵的策展提炼引文；
  - **物理朱砂印章打卡**：轻触“盖章打卡”，触发动态旋转缩放的落印动画与拟真盖印音效，打卡进度持久化存储至本地 `localStorage`；
  - **主图 / 备选图双轨图谱随心切换**：支持在画册主图（高清展陈）与备选图（原版藏图/细节拓片）之间一键切换。展台右上角配备微交互胶囊浮标，底部核心操作栏同步联动，状态即时响应并给予温润气泡反馈。
- **背面 · 深度美育与专家解构**：
  - **美之所在（Beauty）**：从器形、声学、釉质微光漫射、斗拱构造等专业眼力维度提炼美学密码；
  - **带得走的谈资（Trivia）**：提炼最适合社交分享的硬核历史典故与文博冷知识；
  - **古典水墨竖排札记**：传统宣纸纵向排版，呈现典雅策展赏析文字。

### 3. 🎙️ 文博专家原声导览播放系统（音画同频）
- **54 轨高清原声全部就地覆盖**：本地存储 54 个精心录制并经过高保真降噪与垫片拼接的专家级音频（`zh-CN-YunyangNeural` 沉稳大气音色，配 2 秒停顿呼吸感）；
- **动态声波与毫秒级时钟**：14 轨金铜色波形实时随音频起伏律动，精准显示 `当前时间 / 总时长`；
- **交互式进度拖动（Seek）**：点击进度条任意位置，瞬时毫秒级跳转播放进度；
- **逐段台本字幕自动滚屏**：字幕列表随真实播放进度毫秒级高亮，并自动平滑居中滚动至视口；
- **点击字幕任意段落跳转**：轻点台本中的任意自然段，播放器直接跳转到该段落对应的音频位置继续播放。

### 4. 🧭 多维立体筛选与检索中枢
- **周次下拉极速直达**：支持从“第00周 托克托日晷”到“第53周 永乐宫朝元图壁画”任意周次一键定位；
- **核心省份与地域标签**：涵盖北京、河南、湖北、山西、陕西、山东、甘肃、辽宁、四川、河北、江苏、福建等全国文博重点省份，支持按地域大联展快速检索；
- **十二月份岁时雅称**：支持按月份筛选，并配以柳月、杏月、桃月、槐月、蒲月、荷月、巧月、桂月、菊月、阳月、葭月、腊月等东方诗意月份雅称；
- **六大艺术门类**：覆盖百工、金石、古建、书画、造像、壁画六大核心古代艺术领域。

### 5. 🗺️ 一年 54 次相遇 · 全年图鉴护照（Atlas Modal）
- **54 周流光全景瀑布流图鉴**：点击顶部图鉴按钮，即可展开全年 54 件国宝的大地图全景网格；
- **实时点亮打卡进度统计**：实时显示“已点亮 X / 54 件镇馆国宝”徽章进度；
- **打卡状态与图谱视图筛选**：支持“全部 / 仅看已点亮 / 待相遇”分流，并支持一键切换全局 54 宝的主图或备选图全景图谱预览；
- **收藏家数据备份导出**：支持一键导出带 UTF-8 BOM 的标准 JSON 格式打卡护照数据；
- **两步安全重置机制**：避免误操作清空打卡进度。

### 6. ⌨️ 全局案头沉浸快捷键系统
为提供行云流水般的案头微交互体验，应用内置全套原生键盘快捷键（焦点在搜索框时不干扰输入）：
| 快捷键 | 功能说明 | 交互反馈 |
| :---: | :--- | :--- |
| **`Space` 空格键** | 3D 拟真翻转卡片正面与背面 | 触发物理纸张翻折音效与 3D 平滑翻转 |
| **`←` / `→` 方向键** | 切换至上一周 / 下一周国宝 | 智能根据当前筛选列表循环遍历 |
| **`M` 或 `I`** | 一键切换【展陈主图】与【备选图谱】 | 展台右上角胶囊动效与色温渐变反馈 |
| **`P`** | 播放 / 暂停文博专家原声音频导览 | 声波律动与时间轴实时启闭 |
| **`Esc` 退出键** | 快速关闭当前打开的弹窗 | 关闭图鉴护照或壁纸工坊，返回案头主舞台 |

## 📂 项目文件架构

```text
webapp/guobao-calendar/
├── new.html               # 核心主应用单页（Tailwind CSS + 原生 ES6+，全功能闭环）
├── audio-guide-data.js    # 独立解耦的 54 件国宝美育要点、社交谈资与纯净台本库 (168 KB)
├── images/                # 162 张高清国宝真迹展台图谱 (54张主图 week-XX-main.jpg + 54张备选图 week-XX-alt.jpg + 基础图)
├── audio/                 # 54 轨高清文博专家原声导览音频 (week-00.mp3 ~ week-53.mp3, 52.7 MB)
│   └── 54.md              # 原始 54 件国宝导览台本文档源稿
├── 国宝图库-链接.md       # 图片采集溯源文档
└── README.md              # 本项目说明指南
```

### 数据层设计说明
- **解耦结构**：将 54 篇长文导览词、美育核心与谈资从 HTML 中剥离至 `audio-guide-data.js`，通过 `window.GUOBAO_AUDIO_GUIDES` 挂载，既保证了主应用的精简与加载速度，又大幅提升了文博文本的维护与扩展灵活性。
- **纯原生无依赖**：无需 `npm install`、Webpack、Vite 等构建流程，所有样式通过 Tailwind CDN 实时编译，所有音视频均为本地绝对路径加载，支持完全离线部署与运行。

## 🚀 启动与体验指南

由于涉及本地音频与 Canvas 壁纸跨域保护（CORS），推荐通过本地静态 HTTP 服务器打开：

### 方式一：使用 Python 内置简易服务器（推荐）
```bash

cd /Users/xieshijin/jin/learn/ai/webapp/guobao-calendar

# 2. 启动本地静态服务器

# 3. 在浏览器中打开
```

```bash
cd /Users/xieshijin/jin/learn/ai/webapp/guobao-calendar

```
