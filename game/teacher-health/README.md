# 教师身体除锈大作战 · 10分钟职业健康指南 🦴 (3合1全景合辑版)

> **ELI5 (Explain Like I'm 5) 极简绘本风格**：把三大权威健康指南（咽喉、颈肩、下肢、心神）的复杂损耗机制与运动处方，翻译成 5 岁小朋友也能秒懂的生动漫画式网页。

---

## 🌟 核心特色与设计理念

1. **三维反向抵消魔法矩阵 (Reverse Offset Law)**：
   - 🏸 **低头伏案改作业 ➔ 抬头羽毛球**：拉 10 分钟高远球，让仰头看球与挥拍反向拉直低了一天的脖子。
   - 🏊 **重力死死压在腿底 ➔ 泳池水浮力卸重**：划半小时，水压像温柔手掌从四面八方帮血液回流，膝盖零负担。
   - 🌲 **封闭教室粉尘干咳 ➔ 森林吸四步呼四步**：在公园大自然里深呼吸，把粉笔灰换成树木与水的香气。

2. **四大部位报警与防护全覆盖**：
   - 🎤 **冒烟的小喇叭（咽喉金嗓子）**：腹式呼吸、小蜜蜂扩音器、代茶饮（胖大海/麦冬/菊花/金银花），**嘶哑持续超 2 周就医红线**。
   - 🦒 **挂西瓜的长颈鹿（僵硬颈椎）**：屏幕平齐视线、仰睡 1 拳高 / 侧睡 1 拳 + 1 掌厚、伏案 1 小时起身 5~10 分钟。
   - 🦿 **爬满蚯蚓的沉重腿（静脉曲张）**：交替重心站立、穿医用弹力袜、下班温水泡脚 15~20 分钟捏小腿。
   - 🧠 **转不停的小闹钟（心理与胃肠）**：下班物理断联、接纳不完美、三餐规律。

3. **10 分钟办公室除锈 6 大动作谱**：
   - 🐱 **01. 慢动作颈椎米字操**（每个方向停 3 秒，切忌狂甩）
   - 🕊️ **02. 天鹅大展翅**（胸椎伸展，击碎含胸小乌龟壳）
   - 🦎 **03. 壁虎贴墙**（激活肩胛，后背收紧下沉）
   - 🌉 **04. 屁屁搭拱桥**（臀桥练习，臀肌发力替腰椎分担重负）
   - 🦌 **05. 小鹿踮脚尖**（提踵运动，启动下肢肌肉抽水泵）
   - 🎈 **06. 腹式气球深呼吸**（鼓肚皮深呼吸，心神彻底降温）

4. **课间 1 分钟“吸四步·呼四步”节拍打卡器**：
   - 专为课间或办公室碎片时间设计，动态显示 4 秒吸气、4 秒呼气律动；
   - 结束自动通过 **Web Audio API** 原生合成 C5-E5-G5-C6 清脆和弦提示音。
